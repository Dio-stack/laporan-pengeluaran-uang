# 🌸 Admin Panel — Laporan Pengeluaran Uang

Admin panel ini digunakan untuk:
1. Melihat semua data pengeluaran yang diinput oleh user
2. Monitoring kuota AI Gemini (berapa token yang sudah terpakai)

## 🚪 Cara Akses

Buka: `https://dio-stack.github.io/laporan-pengeluaran-uang/admin/index.html`

## 🔐 Login

Username & password admin disimpan di `admin.js`:

```javascript
const ADMIN_CREDENTIALS = {
  username: 'admin_anggun',
  password: 'AnggunGarden2026!@#',
};
```

**Ganti credential ini sesuai keinginan Anda!**

## 📊 Fitur Dashboard

1. **Gemini AI Quota** — Menampilkan sisa token Gemini API hari ini
2. **Penggunaan AI Hari Ini** — Total request dan token yang dipakai user hari ini
3. **Data Pengeluaran User** — Tabel semua pengeluaran terbaru dari user

## ⚙️ Setup Database (WAJIB)

Sebelum admin panel bisa berfungsi, jalankan SQL berikut di **Supabase Dashboard > SQL Editor**:

```sql
-- 1. TABEL ADMIN
create table if not exists public.admins (
  id uuid primary key references auth.users(id) on delete cascade,
  username text not null unique,
  email text not null unique,
  is_superadmin boolean not null default false,
  created_at timestamptz not null default now(),
  updated_at timestamptz not null default now()
);

alter table public.admins enable row level security;

create policy admins_self on public.admins
  for all
  using ((select auth.uid()) = id)
  with check ((select auth.uid()) = id);

-- 2. TABEL TRACKING USAGE AI
create table if not exists public.ai_usage_logs (
  id bigint generated by default as identity primary key,
  user_id uuid references auth.users(id) on delete cascade,
  request_date date not null,
  tokens_used integer not null default 0,
  model_used text,
  status text,
  error_message text,
  created_at timestamptz not null default now()
);

alter table public.ai_usage_logs enable row level security;

create index if not exists ai_usage_logs_date_idx
  on public.ai_usage_logs (user_id, request_date desc);

create policy ai_usage_user_insert on public.ai_usage_logs
  for insert
  with check ((select auth.uid()) = user_id);

create policy ai_usage_admin_select on public.ai_usage_logs
  for select
  using (
    exists (
      select 1 from public.admins a
      where a.id = (select auth.uid())
    )
  );

create policy ai_usage_admin_delete on public.ai_usage_logs
  for delete
  using (
    exists (
      select 1 from public.admins a
      where a.id = (select auth.uid())
    )
  );
```

## 👤 Tambahkan Diri Anda sebagai Admin

1. Buka **Supabase Dashboard > Authentication > Users**
2. Klik user Anda, copy **ID**-nya
3. Jalankan SQL ini (ganti `USER_ID_ANDA`):

```sql
insert into public.admins (id, username, email, is_superadmin)
values (
  'USER_ID_ANDA_DISINI',  -- GANTI DENGAN USER_ID ANDA
  'admin_anggun',
  'admin@example.com',
  true
);
```

## 🔄 Cara Kerja

1. User buka `/admin/index.html` → muncul form login
2. Input username & password → dicek vs `ADMIN_CREDENTIALS`
3. Jika benar → session disimpan di `localStorage` (7 hari)
4. Redirect ke `/admin/dashboard.html`
5. Dashboard mengambil data dari Supabase:
   - `expenses` → data pengeluaran user
   - `ai_usage_logs` → tracking penggunaan AI
   - Gemini Quota API → sisa token hari ini

## 🛡️ Keamanan

- Login menggunakan username & password khusus (terpisah dari auth user biasa)
- Session disimpan di `localStorage` browser
- RLS Policy di Supabase memastikan hanya admin yang bisa baca `ai_usage_logs`
- Data pengeluaran bisa dilihat semua user yang login (sesuai policy `expenses_owner`)

## 🐛 Troubleshooting

| Masalah | Solusi |
|---------|--------|
| Login tidak bisa | Pastikan database sudah di-setup (tabel `admins` ada) |
| Dashboard kosong | Cek console browser (F12) untuk error |
| Quota error | Isi `GEMINI_KEY` yang benar di `admin.js` |
| "Failed to load dashboard" | Pastikan Supabase URL & Key benar |
